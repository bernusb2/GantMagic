# About [GantMagic](https://example.com/gantmagic)

GantMagic is a modern, Free and Open Source project management and Gantt
chart tool. Describe your project as plain text and GantMagic schedules
tasks, levels resources, and generates clean, modern reports — no
GUI required, just a shell, a text editor, and a browser.

Because projects live in a simple, human- and machine-readable text
format, AI coding agents (like Claude) can read and write them directly.
Ask an agent to draft a project plan, add tasks, rebalance resources, or
update a schedule in plain English, and it can edit the `.tjp` file for
you and regenerate the Gantt chart — no manual diagramming required.

GantMagic is written in [Ruby](http://www.ruby-lang.org/en/) and is a
fork of [TaskJuggler](http://www.taskjuggler.org), originally created by
Chris Schlaeger and contributors. It stays compatible with the
TaskJuggler project file syntax while providing a modernized report look
and feel.

## Features and Highlights

### Basic Properties

* Manages tasks, resources and accounts of your project
* Powerful to-do list management
* Detailed reference manual
* Simple installation, runs on Linux, Unix, Windows, MacOS and more
* Full integration with Vim text editor

### Advanced Scheduling

* Automatic resource leveling and task conflict resolution
* Unlimited scenarios (baselines) of the same project for what-if analysis
* Flexible working hours, leave, shift, and multi-timezone support

### Accounting

* Initial and finishing costs for tasks, usage-based costs for resources
* Task- and/or resource-based cost models
* Profit/loss analysis

### Reporting

* Comprehensive, filterable reports tailored to any audience
* Time and status sheet reporting infrastructure
* Project tracking and status reporting with dashboard support

### Scaling and Enterprise Features

* Combine projects into larger projects; central resource allocation
* Roles and complex reporting lines
* Powerful project description language with macro support
* Scales well on multi-core/multi-CPU systems
* Revision control friendly; export to Microsoft Project and CA Clarity

### Web Publishing and Groupware Functions

* HTML reports for web publishing, CSV export, iCalendar export
* Built-in web server for dynamic and interactive reports
* Server-based time sheet system for status and actual work reporting
